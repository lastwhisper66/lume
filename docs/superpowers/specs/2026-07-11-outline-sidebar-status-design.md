# Lume 大纲侧边栏与编辑器状态栏设计

## 目标

为 Lume 增加接近 Typora 的大纲与底部状态栏体验：左侧侧边栏在“文件”和“大纲”之间切换，主编辑区左下角控制侧边栏显隐，右下角显示当前文档词数。

## 范围

本次实现包括：

- 左侧侧边栏顶部增加“文件 / 大纲”页签。
- 从当前活动 Markdown 文档提取 H1–H6 标题并展示层级大纲。
- 点击大纲项只滚动到对应标题，不改变编辑器光标或选区。
- 主编辑区底部增加固定状态栏。
- 状态栏左侧增加侧边栏显示/隐藏按钮。
- 状态栏右侧显示 Typora 风格的“X 词”。
- 应用启动或重启后侧边栏默认隐藏；运行期间保留用户最后一次切换的状态。

本次不包括：

- 持久化侧边栏显隐状态。
- 拖动调整侧边栏宽度。
- 折叠大纲层级。
- 在大纲中编辑或重排标题。
- 点击词数后弹出详细统计面板。

## 布局与组件

### 应用布局

`App` 继续负责应用整体布局，但侧边栏显隐状态由独立的 React 运行时状态控制，初始值为隐藏。隐藏时主编辑区占满可用宽度；底部状态栏始终保留，因此用户随时可以重新展开侧边栏。

主编辑区由三部分纵向组成：

1. 标签栏。
2. 可滚动编辑区域。
3. 固定底部状态栏。

状态栏只属于主编辑区，不延伸到侧边栏下方。

### 侧边栏页签

侧边栏顶部提供“文件”和“大纲”两个页签，默认选中“文件”。两者共享同一侧边栏内容区域，避免长文件树和长大纲同时挤占垂直空间。

文件页继续使用现有 `FileTree`。大纲页使用新的独立大纲组件，从当前活动标签页的 `EditorState.doc` 派生显示内容。

### 大纲呈现

大纲按文档顺序展示 H1–H6：

- 标题层级通过递增的左侧缩进表达。
- 标题文本单行显示，超出宽度时省略。
- 悬停在被省略的标题上时可查看完整文本。
- 文档内容发生变化或活动标签页变化时，大纲同步更新。

## 数据流

大纲与词数都直接从当前活动标签页的 `EditorState.doc` 派生，不保存第二份文档数据。

### 大纲数据

遍历 ProseMirror 文档树并收集 `heading` 节点。每一项至少包含：

- 标题文本。
- 标题级别。
- 标题节点在 ProseMirror 文档中的位置。

活动文档变化时重新计算列表。没有活动文档时返回空列表。

### 词数数据

统计使用文档的可见纯文本，不统计 Markdown 标记符号：

- 每个中文字符计为一个词。
- 连续英文字符或数字序列计为一个词。
- 空白和标点不单独计数。

界面统一显示为“X 词”。没有活动文档时显示“0 词”。

## 交互行为

### 大纲跳转

点击大纲项时，编辑器滚动对应标题进入视野，但不派发改变选区的 ProseMirror transaction。跳转前后的光标和选区必须保持不变。

编辑器组件向应用层提供按 ProseMirror 文档位置滚动的能力。实现可以通过当前 `EditorView` 获取目标 DOM 节点或坐标，并调用浏览器滚动 API；该接口只负责视口定位。

### 侧边栏显隐

- 应用每次启动时侧边栏默认隐藏。
- 点击主编辑区状态栏左侧按钮切换显示或隐藏。
- 运行期间切换文件和标签页不会重置显隐状态。
- 关闭并重启应用后重新恢复为隐藏状态。

### 空大纲状态

没有打开文件时：

- 大纲区域默认不显示任何文字或占位内容。
- 鼠标移入空的大纲区域时，显示“大纲内容为空”。
- 鼠标移出该区域后，提示立即隐藏。
- 状态栏右侧显示“0 词”。

如果已经打开文档但文档内没有标题，大纲列表同样为空；空区域沿用相同的悬停提示行为，避免引入第二种空状态。

## 模块边界

实现应拆分为职责清晰的单元：

- 大纲组件：展示标题层级、空状态悬停提示并发起滚动请求。
- 状态栏组件：展示侧边栏按钮和词数。
- 文档派生工具：从 ProseMirror 文档提取标题和计算词数。
- 编辑器滚动桥接：把文档位置转换为可滚动的编辑器目标，不修改选区。
- `App`：组合布局并持有当前运行期间的侧边栏显隐状态与侧边栏页签状态。

这些单元应依赖现有 Zustand 活动标签页状态，不新增重复的持久化数据源。

## 样式与主题

- 颜色、边框、悬停态继续使用现有 `--lume-*` 主题变量。
- 状态栏高度固定，编辑器内容区域在其上方独立滚动。
- 大纲缩进必须在现有侧边栏宽度内保持可读。
- 显隐按钮应有可访问名称和明确的悬停态。
- 浅色和深色主题下都需保证文字、空状态提示及边框可辨识。

## 异常与边界情况

- 没有活动标签页时，大纲为空且词数为零。
- 标题为空或只含空白时不生成可点击大纲项。
- 标题文本重复时仍以各自的 ProseMirror 文档位置独立跳转。
- 编辑器视图暂未挂载或目标位置失效时，点击大纲项应静默忽略，不改变当前状态。
- 大文档中的派生计算应保持纯函数和线性遍历，避免为每个标题重复扫描整个文档。

## 验证

当前项目没有测试运行器，因此本次至少执行 TypeScript、ESLint 和构建验证，并进行以下手动检查：

1. 应用启动后侧边栏默认隐藏，左下角按钮可反复切换显隐。
2. 侧边栏展开后可在“文件 / 大纲”之间切换。
3. H1–H6 按顺序和层级缩进展示，编辑标题后实时更新。
4. 切换标签页后大纲与词数对应新的活动文档。
5. 点击大纲项只滚动，光标和选区保持不变。
6. 中文、英文、数字和混合文本的词数符合定义。
7. 没有打开文件时显示“0 词”，大纲区域仅在鼠标移入时显示“大纲内容为空”。
8. 打开无标题文档时，大纲空区域沿用相同悬停提示。
9. 浅色与深色主题下状态栏、大纲和交互状态显示正常。

## 成功标准

用户能够在不干扰编辑选区的情况下通过大纲浏览当前文档，并能随时从编辑区底部展开或隐藏侧边栏；右下角持续提供符合约定口径的实时词数。整体布局和交互与用户提供的 Typora 参考图保持一致。
